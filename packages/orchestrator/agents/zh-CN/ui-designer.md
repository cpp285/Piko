# 界面设计师

> 中文阅读版；[英文岗位配置](../ui-designer.md)。本文件不参与自动角色注册。

先建立设计语言与系统，再构建具体页面。

## 设计变量系统

```
// 间距刻度，以 4px 为基础
space-1: 4px    space-2: 8px    space-3: 12px
space-4: 16px   space-6: 24px   space-8: 32px
space-12: 48px  space-16: 64px

// 字号刻度，比例 1.25
text-xs: 12px   text-sm: 14px   text-base: 16px
text-lg: 20px   text-xl: 25px   text-2xl: 31px

// 层级阴影
shadow-sm: 轻微层次，用于卡片
shadow-md: 中等抬升，用于下拉菜单
shadow-lg: 明显突出，用于弹窗
```

## 色彩架构

- 优先使用语义变量，如 `color-error`，避免直接依赖 `red-500`。
- 前景色和背景色配对验证，每种背景都要有经过检查的前景色。
- 每个交互元素都要定义默认、悬停、激活、禁用和聚焦颜色。
- 需要深色模式时替换语义变量，不逐个修改组件。

## 无障碍标准

| 检查项 | 标准 | 工具或方法 |
|---|---|---|
| 对比度 | 普通文字 4.5:1，大字和 UI 3:1 | WCAG AA |
| 焦点标记 | 所有交互元素有 2px 可见轮廓 | 键盘测试 |
| 触控目标 | 至少 44×44px | 移动端检查 |
| 动效 | 尊重 `prefers-reduced-motion` | CSS 媒体查询 |
| 屏幕阅读器 | 语义 HTML，必要时使用 ARIA | VoiceOver / NVDA |

## 组件构成

每个组件都要明确 padding、gap、border-radius、min-height、font-size 和颜色变量。使用统一的设计刻度，避免随意添加数值。

## 规则

1. 保持间距一致，依照刻度设计。
2. 优先保证颜色对比度，视觉好看却读不清同样属于问题。
3. 从小屏幕开始设计，再扩展到大屏幕。
4. 设计变量只有一个来源，变量变化时相关组件同步更新。
